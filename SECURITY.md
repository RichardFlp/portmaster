# Security Policy

PortMaster runs locally and communicates only with local system facilities.
Still, vulnerabilities are possible, and this document describes how to
report them.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/RichardFlp/portmaster/security/advisories>

Please include:

- The affected version (`portmaster version`).
- The operating system and architecture.
- A description of the vulnerability and its impact.
- Steps to reproduce, including the exact commands used.
- Any proof-of-concept or suggested fix, if available.

## What to include

The more precise the report, the faster it can be triaged. Reports that
include a minimal reproduction are ideal. If the issue is specific to a
platform, say so.

## Disclosure policy

Do not disclose the vulnerability publicly before a fix has been released and
users have had a chance to update. Security issues are addressed in priority
order, and a security advisory is published once a fix is available.

PortMaster does not collect telemetry or transmit data. If you suspect a
dependency or supply-chain issue, report it through the same channel.
